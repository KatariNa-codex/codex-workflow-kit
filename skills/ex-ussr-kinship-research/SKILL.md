# Генеалогическое дело и источники

1. Зафиксируйте один исследовательский вопрос. Откройте существующее дело, если оно есть. Для нового дела запустите python -B scripts/init_case.py --case-dir ПУТЬ --research-question ВОПРОС из папки скилла или укажите полный путь к скрипту. Выберите новую папку вне папки скилла.
2. Ведите отдельно людей, источники, утверждения, родственные связи и журнал поиска. Храните точное написание, страницу, дату и происхождение наблюдения. Для локальной копии запустите python -B scripts/hash_artifact.py ФАЙЛ --json. Запишите SHA-256 и локатор в реестр.
3. Разделяйте содержание источника и трактовку. Совпавшая фамилия или индекс дают наводку. Пересказ и его первоисточник относятся к одной цепочке. Недоступный материал и поиск с неполным покрытием оставляют вопрос открытым. Не утверждайте биологическое родство без независимого подтверждения. Не используйте скилл для поиска контактов и адресов живущих людей.
4. Перед итогом запустите python -B scripts/audit_evidence.py --case-dir ПУТЬ --json. Исправьте ссылки на отсутствующие записи и несогласованные статусы. Проверка реестров не устанавливает родство. В отчёте укажите источник каждого вывода, ограничения и следующий шаг.

Python достаточен для трёх локальных помощников. В этой поставке собраны офлайн-помощники и пустые шаблоны, использованные при проверке. Другие возможности описаны у автора исходной версии. [Происхождение и изменения](CHANGES.md)
