# Как начать

Передайте Codex документ и попросите преобразовать его в Markdown. Укажите новый файл для результата и отдельную папку для вложений. Например, «Преобразуй `demo.docx` в `demo.md` и сохрани изображения в новую папку `demo-assets`». Поддерживаемые форматы и требования перечислены в [SKILL.md](SKILL.md).
