# Изменения doc-to-markdown

В промежуточной версии изменён формат вывода Pandoc для таблиц. В рабочей версии добавлены защита от перезаписи, проверка путей вложений, явный UTF-8 и сохранение рабочих ссылок Pandoc. Для репозитория заменены пути пользователя на учебные папки и обновлены памятки. Сравнение конвертеров помечено как историческое.

Рабочая копия сверена с [закреплённым промежуточным снимком](https://github.com/GuruDevvv/my-claude-skills/tree/b5c44a9b7ec4a2620d7c7824cc4df22b940ae6dd/external/doc-to-markdown).
