# Сохранение разрешённого видео или аудио

Передайте Codex ссылку, которую вы вправе использовать, и назовите новую папку для скачивания. Можно начать с просмотра доступных форматов. Для работы нужны уже установленные yt-dlp и ffmpeg. Поддерживаемые действия и параметры перечислены в [SKILL.md](SKILL.md).
