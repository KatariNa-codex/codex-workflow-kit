# Адаптация для Codex

- Область аудита определяется по реальному проекту, а инструкции проверяются с учётом области действия AGENTS.md и AGENTS.override.md.
- Quick проверяет инструкции, память проекта при её наличии и структуру файлов. Full дополнительно проверяет Git и описанные автоматизации. При недоступности делегирования проверки выполняются последовательно.
- Путь к памяти memory-kit определяется через конфигурацию активного профиля и полный путь проекта. Обход соседних профилей и личных хранилищ исключён.
- Пропуски необязательных компонентов отражаются в покрытии. Выводы опираются на наблюдаемое влияние. Содержимое файлов с ключами и исходные настройки с возможными секретами в отчёт не попадают.
- Отчёт по умолчанию сохраняется в docs/audits подтверждённого проекта без перезаписи. Возможен ответ только в чате. Сравнение с прошлым отчётом проверяется по текущим данным.
