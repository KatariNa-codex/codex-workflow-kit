# Адаптация idea-storm для Codex

Сохранены быстрый и полный режимы, три финалиста, слепая проверка с контрольным вариантом и решение с проверяемым условием. Используется штатная делегация Codex без запуска отдельного CLI. При ограничениях указано число рецензентов; собственная проверка координатора отмечается отдельно. Отчёт сохраняется в docs проекта или в выбранной папке.
