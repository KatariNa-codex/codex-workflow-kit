# Адаптация multi-layer-review для Codex

Сохранены пять ракурсов, проверка по источникам, слепые рецензии и сводка разногласий. Claude Code и отдельный Codex CLI заменены штатной делегацией Codex. При недоступной делегации ракурсы проверяет координатор с явной отметкой. По умолчанию отчёт сохраняется в docs/reviews; папка памяти используется по действующим инструкциям проекта и после сверки.
