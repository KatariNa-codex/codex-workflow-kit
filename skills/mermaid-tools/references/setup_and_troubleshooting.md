# Запуск и проверка диаграмм Mermaid

Из папки скилла запустите скрипт установленным Python. Вход — существующий Markdown с блоками Mermaid. Папка вывода должна быть новой.

```text
python -B scripts/extract_and_generate.py INPUT.md NEW_OUTPUT_DIRECTORY
```

- В системе должен быть доступен `mmdc` и настроена его среда. Если в Windows `mmdc` найден как оболочка `.cmd`, `.bat` или `.ps1`, скрипту нужны установленный `node` и файл `node_modules/@mermaid-js/mermaid-cli/src/cli.js` рядом с оболочкой.
- Если вывод уже существует, выберите новое имя папки. При ошибке проверьте сообщение и содержимое новой папки. Скрипт сохраняет частичный результат для проверки.
- Проверьте PNG визуально. Автоматическая проверка оценивает структуру изображения, читаемость подписей и компоновку проверяет человек.
- Прежний shell-скрипт возвращает подсказку о переходе на Python.
