# Проверки Workflow Kit 1.1.0-preview.6

На распакованном ZIP прошли 215 автоматических проверок, в том числе восемь сценариев жизненного цикла установки, четыре проверки изоляции, хуков и команды проверки и 13 сценариев переноса с имитацией Desktop.

Установщик выводит команду проверки для выбранного профиля Codex. Архиватор читает записи этого профиля, а отчёт о памяти работает с локальными данными.

Живая установка, подтверждение доверия хукам и перенос в интерфейсе Desktop для этой версии не проверялись. Комплект опубликован как preview.
