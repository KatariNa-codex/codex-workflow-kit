# Проверки Workflow Kit 1.1.0-preview.7

Из распакованного ZIP прошли 222 автоматические проверки. В их числе десять сценариев жизненного цикла установки, четыре проверки работы только с Codex, 13 сценариев переноса с имитацией Desktop и пять проверок остановки фоновых процессов на вымышленных данных.

Перед отключением установщик сверяет профиль, корень проектов и запись об установке. При ошибке он откатывает изменения. Для остановки фонового процесса нужно явно выбрать PID. Перед остановкой скрипт повторно сверяет время создания процесса.

Живая установка, подтверждение доверия хукам и перенос в интерфейсе Codex Desktop для этой версии ещё не проверены. Сборка выпущена как preview.
