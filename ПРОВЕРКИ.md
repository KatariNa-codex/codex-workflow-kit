# Проверки Workflow Kit 1.1.0-preview.4

Из распакованного ZIP прошли 219 автоматических проверок. Они охватывают хуки, в том числе целые ссылки на ветки при сокращении HANDOFF, бюджет проектных правил Codex, установку, обновление, откат и перенос с имитацией Desktop.

В отдельном профиле Windows проверено обновление с preview.3. Сохранились HANDOFF, связанный файл проекта, журнал и настройка автосинхронизации. Стартовый хук выдал следующий шаг и путь к полной записке.

В живом Codex Desktop ещё предстоит проверить доверие хукам и полный перенос с закреплением чата. Комплект остаётся тестовой сборкой.
