# Начать работу с Workflow Kit

Workflow Kit помогает Codex сохранять состояние проекта, выбирать исполнителей и продолжать работу в новом чате. Этот выпуск предназначен для Codex Desktop на Windows. Один установщик настраивает выбранный профиль Codex и сразу подключает Session Advisor.

## Установить через Codex

1. Скачайте [Workflow Kit 1.1.0-preview.16](Workflow-Kit-1.1.0-preview.16.zip). Для проверки скачивания рядом есть [контрольная сумма ZIP](Workflow-Kit-1.1.0-preview.16.zip.sha256).
2. Откройте Codex Desktop. Приложите ZIP к сообщению или укажите путь к нему.
3. Скопируйте сообщение ниже. Codex проверит комплект и необходимые программы перед установкой.

```text
Установи Workflow Kit из этого ZIP. Проверь архив и прочитай INSTALL.md внутри. Определи мой активный профиль Codex и папку проектов, затем покажи предпросмотр. Если обнаружишь конфликт с моими файлами или настройками, остановись и объясни, что нужно уточнить. Если конфликтов нет, выполни установку и проверку тем же install.py.

Покажи мне, где подтвердить доверие хукам. После моего подтверждения проверь, что в новой сессии учебного проекта виден точный следующий шаг из его HANDOFF. Затем покажи, как мне самому попробовать «Стоп» и «Переноси» на учебном проекте.
```

Для установки нужны Python и Node.js. Для операций с репозиториями нужен Git. При новой установке автосинхронизация Git включена. Как она работает, как её отключить и как запустить тот же установщик вручную, описано в файле `INSTALL.md` внутри ZIP.

## Попробовать команды

Доверие хукам подтверждаете вы. После этого начните новую сессию в учебном проекте. Сначала попросите Codex назвать точный следующий шаг из учебного HANDOFF. Когда он его покажет, попробуйте «Стоп», затем «Переноси». Памятка находится в `docs/COMMANDS.md` внутри ZIP.

Команда «Продолжай до переноса» ведёт активную работу в этом чате, даже если отдельного ТЗ нет. Codex сам переходит к следующим доступным этапам. У границы контекста он выполняет СТОП, сохраняет точку продолжения и ждёт отдельной команды на перенос. Если итог выглядит промежуточным или причина остановки неясна, советник один раз предлагает его сверить.

Установка, обновление и логика переноса проверены на тестовых данных. Подтверждение хуков и полный перенос с закреплением чата в отдельном профиле Codex Desktop ещё не проверены. [Результаты проверок](ПРОВЕРКИ.md)
