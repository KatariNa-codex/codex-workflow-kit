# Русские тексты и встречи для Codex

Пять скиллов для подготовки и вычитки русских текстов, составления протоколов и разбора встреч по готовой расшифровке.

[Скачать ZIP](downloads/workflow-kit-text-meetings-1.0.0.zip) · [Контрольная сумма SHA-256](downloads/workflow-kit-text-meetings-1.0.0.zip.sha256).

## Установить

Распакуйте ZIP и откройте проект в Codex. Попросите скопировать выбранные папки из skills в .agents/skills проекта или скопируйте их вручную. Если используете ru-writing, установите вместе с ним human-text и ru-text из архива. Одноимённые папки, которые у вас уже есть, сначала сравните с новыми.

## Состав и проверка

| Скилл | Назначение | Что проверено |
| --- | --- | --- |
| [human-text](../skills/human-text/SKILL.md) | Помогает писать и редактировать русский текст. Для локального помощника нужен Python | Найден заранее внесённый речевой штамп |
| [ru-text](../skills/ru-text/SKILL.md) | Проверяет грамматику, пунктуацию и типографику | При вычитке сохранены реквизиты, цитата, ссылка и срок |
| [ru-writing](../skills/ru-writing/SKILL.md) | Связывает черновик с вычиткой и подбирает глубину правок по жанру | При типографской правке сохранились авторские слова и порядок абзацев |
| [meeting-minutes-taker](../skills/meeting-minutes-taker/SKILL.md) | Готовит протокол по предоставленной расшифровке | Решение подтверждено цитатой, исполнители и сроки указаны только там, где названы |
| [meeting-insights-analyzer](../skills/meeting-insights-analyzer/SKILL.md) | Разбирает поведение и ход обсуждения по предоставленным материалам | Наблюдения привязаны к репликам. Предположения отделены от наблюдений |

Codex CLI обнаружил все пять скиллов после установки из распакованного ZIP. Проверки проведены на вымышленных текстах. Голосовую запись надо сначала расшифровать. Эти скиллы работают с готовым текстом и сами не отправляют протокол участникам.

В каждой папке есть лицензия и сведения о происхождении и изменениях.
