# Исследования и работа с продуктом для Codex

Восемь скиллов для проверки идеи, исследований, аналитики, экспериментов, цены и запуска продукта.

[Скачать ZIP](downloads/workflow-kit-product-research-1.0.0.zip) · [Контрольная сумма SHA-256](downloads/workflow-kit-product-research-1.0.0.zip.sha256).

## Установить

1. Распакуйте ZIP и откройте свой проект в Codex.
2. Попросите Codex скопировать выбранные папки из skills в .agents/skills вашего проекта. Для ручной установки скопируйте эти папки сами. Существующие одноимённые папки сначала сравните с новыми.
3. В новом чате откройте SKILL.md выбранного скилла. Для первой пробы достаточно учебных данных и самого Codex. Подключайте сервисы и реальные источники только для задач, которые этого требуют.

## Состав и проверка

| Скилл | Назначение | Что проверено на учебных данных |
| --- | --- | --- |
| [ab-testing](../skills/ab-testing/SKILL.md) | План эксперимента со случайным распределением | Гипотеза, основной показатель, ограничение вреда и оценка выборки |
| [analytics](../skills/analytics/SKILL.md) | План измерения событий и воронки | Имена событий, параметры, исключение повторов, шаги проверки записи |
| [customer-research](../skills/customer-research/SKILL.md) | Синтез интервью и отзывов | Связь выводов с заметками, учёт противоречащих свидетельств |
| [deep-research](../skills/deep-research/SKILL.md) | Исследование с оценкой источников | Сопоставление вымышленных источников, ограничения выводов и критерий решения |
| [launch](../skills/launch/SKILL.md) | План запуска продукта | Проверка готовности, ранний запуск, условия перехода к следующему этапу |
| [marketing-plan](../skills/marketing-plan/SKILL.md) | Маркетинговый план по этапам | Начальный разбор и план согласования, без публикации или отправки материалов |
| [pricing](../skills/pricing/SKILL.md) | Модель цены и проверка гипотез | Сопоставление цены за пользователя и цены за площадку, план исследования |
| [product-check](../skills/product-check/SKILL.md) | Проверка идеи по пяти вопросам | Барьер перехода, оценка на основе данных и ближайший эксперимент |

Codex CLI обнаружил все восемь скиллов после установки из распакованного ZIP в отдельный проект. Проверки проводились на вымышленных сценариях. Установка внешних систем аналитики, набор участников и запуск реальных кампаний в этот проход не входили.

Лицензия и сведения об исходной версии и изменениях есть в каждой папке.
