# Browser и Computer Use

Browser помогает Codex работать с веб-страницами. Computer Use позволяет управлять окнами приложений Windows. Для доступа к вкладкам вашего Edge понадобится расширение ChatGPT.

## Подключить Edge

1. В приложении ChatGPT Desktop откройте **Настройки → Computer Use**. Найдите **Microsoft Edge** в списке браузеров или в **More browsers**.
2. Следуйте приглашению установить плагин, если оно появится. Нажмите **Install** рядом с Edge и установите расширение в том профиле браузера, которым пользуетесь.
3. Вернитесь в **Computer Use** и убедитесь, что рядом с Edge появилась кнопка **Manage**. Включите переключатель Edge, чтобы он появился в меню `@`.

**Проверка.** В новом чате Codex выберите `@Edge` и попросите открыть `https://www.python.org/` и назвать заголовок страницы. Убедитесь, что вкладка открылась в нужном профиле Edge. [Инструкция по расширению](https://learn.chatgpt.com/docs/chrome-extension)

## Подключить приложения Windows

В **Настройки → Computer Use** найдите **Any App**. Если доступна кнопка установки, нажмите её и пройдите настройку. В тестовом запросе попросите открыть «Калькулятор» и вычислить 2 + 2. Подтвердите доступ к приложению, если Codex его запросит. [Инструкция по Computer Use](https://learn.chatgpt.com/docs/computer-use)
