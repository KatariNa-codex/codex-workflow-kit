# Скиллы, MCP и инструменты для Codex

Четыре скилла для разработки инструментов, подготовки скиллов и проверки их файлов перед установкой.

[Скачать ZIP](downloads/workflow-kit-skill-tools-1.0.0.zip) · [Контрольная сумма SHA-256](downloads/workflow-kit-skill-tools-1.0.0.zip.sha256).

## Установить

Распакуйте ZIP и откройте учебный или рабочий проект в Codex. Скопируйте выбранные папки из skills в .agents/skills проекта или попросите об этом Codex. Если одноимённый скилл уже установлен, сначала сравните его файлы с новой версией. Откройте SKILL.md нужного скилла для выбора зависимостей.

## Состав и проверка

| Скилл | Назначение | Что проверено |
| --- | --- | --- |
| [mcp-builder](../skills/mcp-builder/SKILL.md) | Проектирует MCP-серверы и их инструменты | Учебный Python-сервер с MCP SDK обнаружен клиентом через stdio. Вызов инструмента вернул ожидаемое значение |
| [skill-conductor](../skills/skill-conductor/SKILL.md) | Помогает создавать, проверять и распространять скиллы | Проверен русскоязычный SKILL.md и собран .skill. Повторная сборка поверх существующего файла отклонена |
| [skill-eval](../skills/skill-eval/SKILL.md) | Проверяет структуру и статические признаки в файлах скилла без запуска его кода | Найден заранее внесённый дефект метаданных. Сформирован отчёт об охвате |
| [tool-design](../skills/tool-design/SKILL.md) | Помогает спроектировать схему и описание инструмента | Получены схема, описание обязательного аргумента и результат проверки описания |

Для проверенного маршрута MCP нужен официальный Python SDK mcp 1.x. Локальная упаковка Skill Conductor использует Python и PyYAML. Статический проход Skill Eval и проверенный помощник Tool Design работают локально в Python.

Codex CLI обнаружил все четыре скилла после копирования из распакованного ZIP. Внешние аккаунты, удалённые MCP-сервисы и сравнение качества моделей в этом проходе не проверялись. Статический отчёт сам по себе не подтверждает безопасность скилла.

Лицензия и сведения об исходной версии и изменениях есть в каждой папке.

[Официальный MCP SDK для Python](https://github.com/modelcontextprotocol/python-sdk)
