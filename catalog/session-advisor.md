# Session Advisor

Советник следит за доступной оценкой заполнения контекста в Codex. При достижении 80% он повторяет предложение о переносе после каждого ответа в этом чате, в том числе после «не переносим» и сжатия контекста. Перенос запускается по прямой просьбе пользователя через Workflow Kit.

[Скачать ZIP 1.0.1](downloads/workflow-kit-session-advisor-1.0.1.zip) · [SHA-256](downloads/workflow-kit-session-advisor-1.0.1.zip.sha256)

**Подключение.** Codex Desktop на Windows, Python и Node.js. В ZIP есть инструкция с предпросмотром, установкой и подтверждением доверия хукам в Codex.

**Исходник и лицензия.** Локальное дополнение Workflow Kit, версия 1.0.1. Исходники и MIT-лицензия входят в архив.

**Проверено.** Повторы и отсутствие дублей, сохранение напоминания после отказа и сжатия контекста. Установка проверена в изолированном профиле со сторонним хуком. В 1.0.1 текст передаётся Codex перед ответом. Реальный показ исправленного напоминания в Desktop ещё проверяется.
