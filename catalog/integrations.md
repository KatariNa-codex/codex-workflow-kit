# Плагины, MCP и другие надстройки

Плагины подключаются в Codex Desktop через раздел «Плагины». Установите нужный плагин, войдите в свой аккаунт и подтвердите запрошенный доступ. Для первой проверки используйте учебный файл, письмо или репозиторий. [Официальная инструкция](https://learn.chatgpt.com/docs/plugins)

| Что нужно | Где начать | Состояние инструкции |
| --- | --- | --- |
| Открывать страницы и работать с окнами Windows | [Browser и Computer Use](browser-computer-use.md) | Шаги для Edge и Any App |
| Читать репозитории и задачи | [GitHub](github.md) | Подключение аккаунта и проверка на учебном репозитории |
| Искать письма | [Gmail](gmail.md) | Подключение аккаунта и проверка поиска |
| Работать с материалами NotebookLM | [nlm-skill и MCP](nlm-skill.md) | Инструкция автора для CLI, скилла и сервера MCP |
| Работать с документами, таблицами и презентациями, подключать Canva, Calendar, Sites или Telegram | [Каталог плагинов Codex](https://learn.chatgpt.com/docs/plugins) | Ищите нужное название в Desktop. Доступность зависит от рабочего пространства. Установку с нуля для этих дополнений отдельно не проверяли |
| Подключить другой MCP-сервер | [Справка Codex по MCP](https://learn.chatgpt.com/docs/extend/mcp) | Используйте инструкцию поставщика для сервера и свой доступ |
| Попробовать TokenEconomizer | [Проект Microsoft](https://github.com/microsoft/TokenEconomizer) | Самостоятельное дополнение. Совместная установка и откат адаптации для Windows рядом с Workflow Kit ещё не проверены |

## Что уже поставляется с основным комплектом

Память, её хуки, правила выбора исполнителей и команда «Переноси» входят в основной Workflow Kit. Перенос использует управление чатами из Codex Desktop. Полный сценарий с подтверждением хуков и закреплением нового чата в отдельном окне пока открыт. [Установка Workflow Kit](../README.md)

## Что пока доступно только в рабочей среде автора

Для локального Node REPL, дополнительных проверок проекта и карточек консультаций пока нет проверенной самостоятельной установки. Для карточек отдельно предстоит отделить интерфейс от личных связей между чатами.
