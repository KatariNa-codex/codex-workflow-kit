# GitHub

Плагин помогает Codex читать содержимое репозиториев, задачи и запросы на слияние.

## Подключить

1. В ChatGPT Desktop откройте **Плагины**, найдите **GitHub** и установите его.
2. Подключите свой аккаунт GitHub в окне подключения. Выберите репозитории, к которым хотите дать доступ.
3. Откройте новый чат Codex.

**Проверка.** Попросите `@GitHub` назвать заголовок README вашего учебного закрытого репозитория и дать ссылку на файл. Так можно проверить доступ именно к выбранному репозиторию. [Установка плагинов](https://learn.chatgpt.com/docs/plugins) · [Подключение GitHub](https://help.openai.com/en/articles/11145903-connecting-github-to-chatgpt)

Для публикации из локальной папки настройте вход в Git отдельно. [О входе в GitHub из Git](https://docs.github.com/en/get-started/git-basics/caching-your-github-credentials-in-git)
